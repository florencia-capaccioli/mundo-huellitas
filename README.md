# Mundo Huellitas 🐾

**Todos merecen un hogar.**

## Descripción

Mundo Huellitas es una aplicación móvil que busca facilitar la adopción responsable de mascotas, conectando a personas interesadas en adoptar con refugios que buscan un hogar para los animales.

## Objetivo

Promover la adopción responsable y facilitar el encuentro entre mascotas que necesitan un hogar y personas dispuestas a brindarles amor y cuidados.

## Tecnologías

- React Native
- Expo
- JavaScript
